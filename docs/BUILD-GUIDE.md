# 八类武器与队伍构筑

基础武器按三个独立问题定位：攻击方式是近战还是远程，作用于单体还是群体，伤害在命中时结算还是之后持续跳伤。三条轴组合成八种战斗风格。

## 八种基础武器

| 距离 | 目标 | 伤害结算 | 职业 / 武器 | 战斗表现 |
| --- | --- | --- | --- | --- |
| 近战 | 单体 | 单次 | 维修工 / 重型扳手 | 短暂蓄力后重击一个近身目标 |
| 近战 | 单体 | 持续 | 消防员 / 救援电锯 | 贴近一个目标连续切割，持续工作会过热 |
| 近战 | 群体 | 单次 | 商场保安 / 警棍 | 扇形横扫并短暂震慑近身感染者 |
| 近战 | 群体 | 持续 | 环卫工 / 旋转清障刷 | 高频旋扫周围目标并使其湿润 |
| 远程 | 单体 | 单次 | 猎人 / 蓄力重弩 | 蓄力后远距离重击，优先瞄准精英与首领 |
| 远程 | 单体 | 持续 | 化工人员 / 酸液喷枪 | 酸液附着在一个目标身上，每半秒腐蚀一次 |
| 远程 | 群体 | 单次 | 拆除工 / 投掷式破拆药包 | 投掷至密集处，落地时造成一次范围爆破 |
| 远程 | 群体 | 持续 | 化学教师 / 自制燃烧瓶 | 投掷到一片区域，留下持续灼烧的火区 |

化学教师、维修工、保安是三个开局角色。消防员、环卫工、猎人、化工人员和拆除工通过整备招募；招募同类成员每两人提升一档对应武器协同，最多三档。

## 武器改装

每局最多获得16项改装，同一项只学习一次。八种武器各有两项专属改装，另有六项通用改装。

| 武器 | 改装 | 效果 |
| --- | --- | --- |
| 重型扳手 | 震地重击 / 防守反击 | 重击追加前方冲击波 / 命中获得短时护盾 |
| 救援电锯 | 蒸汽排压 / 斩杀散热 | 过热释放范围冲击 / 斩杀降低热量 |
| 警棍横扫 | 震慑节奏 / 前后照应 | 每第三击产生眩晕脉冲 / 攻击追加反向横扫 |
| 旋转清障刷 | 外圈清道 / 积水导流 | 每第三次旋扫扩大范围 / 湿润命中时追加电弧 |
| 蓄力重弩 | 破甲分矢 / 三箭连发 | 命中精英或首领时分裂弩矢 / 蓄力后追加短间隔射击 |
| 酸液喷枪 | 延长腐蚀 / 高浓配方 | 延长持续腐蚀时间 / 提高腐蚀跳伤 |
| 破拆药包 | 延迟震荡 / 链式装药 | 爆破后延迟再冲击 / 爆破击杀触发小型连爆 |
| 自制燃烧瓶 | 火线封锁 / 交叉投掷 | 沿投掷方向铺开火区 / 周期性追加侧投 |
| 通用改装 | 轻装疾行、急救回收、行进蓄力、护送约定、紧急注射、物尽其用 | 移动、治疗、救援和拾取带来可搭配的战术收益 |

改装牌只从当前已拥有的武器中抽取专属选项，避免出现没有触发来源的牌。

## 核心装备

装备由全队共用四槽。部分装备要先拥有相应标签，才会进入候选：

| 装备 | 触发方式 | 来源要求 |
| --- | --- | --- |
| 回收电池 | 拾取物资后向附近目标释放电弧 | 无 |
| 并联线圈 | 电击湿润目标时追加导电 | 电击＋湿润 |
| 冷却循环罐 | 清障刷命中时为附近电锯散热 | 湿润＋电锯 |
| 腐蚀滤网 | 近战命中腐蚀目标后获得护盾 | 近战＋腐蚀 |
| 压力阀 | 电锯过热时喷出强酸 | 电锯 |
| 急救保温箱 | 溢出治疗转化为护盾 | 治疗 |
| 废油滤芯 | 燃烧目标死亡后留下余火 | 火焰 |
| 共振扩音器 | 声波标记提升火焰和酸液伤害 | 声波 |
| 延时引信 | 破拆药包命中燃烧目标时引发爆燃 | 爆破 |
| 磁吸背带 | 周期拾取后吸引附近物资 | 无 |
| 动能飞轮 | 移动蓄力后为队长下一击附加冲击 | 无 |
| 应急分装盒 | 使用急救包后下一击产生击退脉冲 | 治疗 |

## 组合思路

- 清障刷先让周围感染者湿润，线圈和回收电池再把近身压力转化为电弧伤害。
- 酸液降低装甲敌人的防护后，维修工和消防员可以安全地集中处理单体威胁。
- 警棍将敌人压在近身范围，化学教师和拆除工负责区域封锁与瞬间清场。
- 猎人负责远处精英目标；磁吸背带和行进蓄力让队伍在移动搜刮时也能维持输出。

这是可自由混搭的构筑方向，不要求凑齐固定队伍，也没有隐藏套装奖励。八种基础武器仍保持各自的目标范围与伤害节奏。

## 共同规则

追加攻击默认按较低伤害结算，不能递归触发其他追加攻击。射线、弹道和地面伤害遵守实体墙遮挡；投掷武器可越过低掩体。持续伤害按跳数结算；相同来源的重叠火区刷新持续时间，不重复叠加伤害。

武器最高五级，每级增加12%基础伤害。同类幸存者每两人提升一档武器协同，最多三档。
