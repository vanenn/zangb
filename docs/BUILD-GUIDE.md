# 构筑图鉴 · 第三版

一局最多选择16次改装，每项只学一次。装备全队共用四槽，无备用背包；所有内容第一局即可获得，专属候选要求已拥有对应武器。

## 先从两个动作之间的联系开始

| 方向 | 人员与装备 | 操作选择 |
| --- | --- | --- |
| 水电 | 环卫工＋电工；回收电池、并联线圈、冷却循环罐 | 在积水处交战，绕圈拾取充电；若没有消防员，暂不考虑冷却罐 |
| 腐蚀近战 | 化工＋消防员＋护士；腐蚀滤网、压力阀、急救保温箱 | 利用窄口让酸液覆盖敌人的来路，等护甲被腐蚀再贴近 |
| 诱饵火场 | 音响师＋化学老师＋快递员；废油滤芯、共振扩音器、延时引信 | 用声源聚怪，让火区与落砖覆盖同一片区域 |
| 回收游击 | 快递员＋护士；磁吸背带、动能飞轮、应急分装盒 | 主动换位置、拾取物资和急救包，将补给转成下一轮攻击 |

这些只是搭配示例。水电队也能带腐蚀滤网保护近战，火场队也能带磁吸背带改善回收；没有凑齐后自动赠送的套装奖励。

## 共同规则

追加攻击默认造成原攻击50%伤害，不能继续派生自身或其它追加攻击。射线、分裂、闪电跳跃和地面伤害遵守实体墙遮挡；可抛射武器能越过低掩体。闪电主链、支链、线圈和末端放电合计最多伤及12名不同目标。

护盾通常为8点、持续3秒，合计不超过最大生命30%；护盾类与冷却类装备通常全队冷却4秒。急救包回复4生命，每名护士的改装产包间隔至少4秒。护士持续回血不超过每秒最大生命3%。

同一来源的重叠持续区域刷新而不重复结算，不同成员分别贡献。装备产生的地面区域默认持续3秒、半径65，按每秒触发伤害25%结算。敌人有击退与眩晕上限，首领更难被控制。

四槽满后，替换界面先展示失去与获得的效果。拆掉提供触发来源的装备可能使另一件装备暂时失效，构筑档案会列出缺少的来源。

武器强化仍在整备购买，最高五级，每级只增加12%基础伤害。同业2/4/6人协同仍存在；同名成员可以超过六人，但不再增加协同层级。
