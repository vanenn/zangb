# 第三版系统与数值

构筑由36项一次性机制改装、12件核心装备、四个装备槽与实际招募的成员组成。无永久战斗加成，没有新增地图或职业。

## 模块与安全规则

构筑配置在 data/mods.json 与 data/equipment.json，难度与编组在 data/waves.json。run_state.gd 管理局内状态与候选，build_runtime.gd 处理命中、击杀、拾取、治疗、救援、过热和全队冷却；weapons_runtime.gd 执行攻击，scavenge.gd 处理搜刮。队形、地图、招募商店与局外进度仍分开管理。

追加攻击携带来源成员和追加标记；死亡在回调前落账，不能重复掉落。地面持续伤害按来源去重。普通敌人0.5秒内最多推移10像素，首领再乘0.12；眩晕有抗性间隔，避免人数增多后永久控制。

奖励随机流由局种子、奖励阶段和刷新次数派生，战斗与画面随机消耗不会改变相同条件下的选牌。检查点保存候选、刷新、难度、构筑、队伍、物资、场景状态和随机状态；出发时清空短时充能。

## 一次性旧档重置

只处理存档根目录中的 run/progress/settings 三个名称与 .json、.json.bak、.json.tmp、.pre-v2.json 后缀组合。先校验绝对父目录，不递归删除目录。成功写入 schema.json 版本3后不再清理；标记丢失但已有版本3对局或进度时保留新档并重建标记。初始化失败时阻止进入游戏。开发测试始终使用 tests/user 内的隔离目录。

## 美术与验证边界

第三版继续使用七张透明图集、28段六帧动画。新增行为通过不同的发射次数、方向、落点、铺设范围和发生时机展示；没有为36项改装另外制作36套独立动画。人物仍采用绘本图像分层动作，声音为本地合成。

自动模拟检查规则与相对表现，不能代替真人判断手感和难度。验收报告区分规则测试、固定场景、完整模拟与窗口输入检查，并列出尚未解决的平衡限制。
