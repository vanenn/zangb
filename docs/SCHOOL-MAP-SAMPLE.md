# 第七中学 · 地图样板 01

这是一张固定学校地图的布局试玩，用来评审路线、通路宽度、房间连接与奖励分布。不是随机地图版本，也不是完成的战斗关卡。

双击 `SchoolMapSample.exe`。初始显示总览；点击右侧路线按钮比较三条路线。点击地图中的房间，查看该处的用途。点击“继续走图”进入实地走图。

## 操作

- WASD / 方向键：移动，门与家具有真实碰撞，同伴会绕路跟随。
- E：靠近目标后按住。救援、搜刮优先于门。
- Tab：总览 / 走图切换，保留本次走图状态。
- F：开启或关闭墙体视野遮挡。默认开启，视野半径480；低矮家具不遮挡视野。
- Esc：暂停，开箱与撤离计时也会停止。
- 重新走图：重置本样板的奖励、门、位置和计时。

## 三条路线

1. 主路：南门 → 西楼梯厅 → 教学主廊 → 东楼梯厅 → 北侧安全门。最短路线，预留精英瓶颈。
2. 上路：西楼梯厅 → 医务室 → 实验室 → 北侧安全门。急救柜恢复35生命；消防员救援后成为可见同伴；实验室东侧木门可打开，南门也可回主廊。
3. 下路：南门 → 图书室 → 配电室 → 东楼梯厅 → 北侧安全门。书架切割通道；图书室北门可回主廊；配电室提供设备箱。

路线虚线来自同一份碰撞配置，并逐段检查16像素人物半径的通行。关闭所有木门后仍有一条永久通路连通出生点与出口。

## 已经接入的交互

- 救援：按住E 1.6秒，消防员加入并跟随，只结算一次。
- 急救柜：按住E 2秒，生命由60恢复至95，只结算一次。
- 设备箱：按住E 2秒启动，等待8秒，再按住E领取。记录电池样件和30物资；电池战斗触发未接入。
- 木门：按住E 0.6秒开关；有人在门框内时不能关门。同步改变碰撞、寻路和视野遮挡。
- 警铃：可关闭，记录机关状态；本样板没有敌人听觉。
- 撤离：按住E 2秒启动，等待15秒，再在终端按住E离开。未拿奖励不补发。

## 范围与限制

- 红色圆区是遭遇预留标记，没有生成可战斗敌人。没有战斗伤害、成长选牌或随机生成。
- 这里的实测步行耗时不含战斗，不能用于宣称正式关卡时长。
- 视野展示当前墙体遮挡，未接入探索记忆与战斗锁定。关闭遮挡只是布局检查功能。
- 样板不加载游戏进度模块，不读取、清理或写入正式对局、战绩和设置。走图状态在关闭程序后丢弃。
- 素材沿用项目现有角色、地板和物件；来源见 `assets/LICENSES.md`。

## 源码

- `data/school_sample.json`：房间、墙体、门、家具、交互点、路线及遭遇预留。
- `scripts/school_sample_map.gd`：复用正式项目的碰撞与寻路。
- `scripts/school_sample.gd`、`scripts/school_sample_layer.gd`：走图、交互、视野与界面。
- `school_sample.tscn`：独立入口。编辑器直接运行该场景；项目命令行 `-- --school-map` 也可进入。
- `tests/school_sample.gd`：实际几何与交互测试，结果在 `tests/school-sample-result.json`。

本地图是第一张布局样板，还需要人工走图评价道路宽度、视野手感和绕路意愿；当前测试不证明遭遇压力或战斗平衡。
