# 教学楼关卡：真实建筑参考

核查日期：2026-09-22。用途是《灰城幸存者》的虚构学校关卡；下列资料用于空间观感与功能组合，不作为施工设计或建筑合规依据。

## 1. 北京建筑大学教学5号楼空间改造 / C+ Architects

- 项目：北京西城区展览馆路老校区，原楼建于1956年，改造项目年份2017年，页面列示面积2300平方米。
- 来源性质：ArchDaily刊载的建筑师项目说明，正文明确标注“来自建筑师”；属于项目设计方提供的一手说明，由建筑媒体承载。
- [项目说明与图库](https://www.archdaily.cn/cn/874652/bei-jing-jian-zhu-da-xue-star-jiao-xue-5hao-lou-kong-jian-gai-zao-c-plus-architectsjian-zhu-she-ji-shi-wu-suo)
- [首层平面图页面](https://www.archdaily.com/zh/874652/bei-jing-jian-zhu-da-xue-star-jiao-xue-5hao-lou-kong-jian-gai-zao-c-plus-architectsjian-zhu-she-ji-shi-wu-suo/5953ae1bb22e38a88b0001b6-bei-jing-jian-zhu-da-xue-star-jiao-xue-5hao-lou-kong-jian-gai-zao-c-plus-architectsjian-zhu-she-ji-shi-wu-suo-shou-ceng-ping-mian)

已被正文支持的观察：

1. 原楼采用狭长的中央走廊，教室位于走廊两侧，适合作为长条教学楼的空间原型。
2. 建筑两端分别设一座楼梯，可参考为相距较远的两条上下楼路径。
3. 改造后在南侧中央增设面向花园的出入口及公共活动空间，中央入口与两端楼梯能形成清楚的方向关系。
4. 二层中央局部楼板拆除，形成两层通高的阶梯教学公共空间；北侧另有评图、讨论空间。因此连续教室序列可以被较大的公共节点打断。
5. 项目保留并展示木屋架，屋顶增加采光天窗；真实项目的屋顶形态不能当作平屋顶停机区的依据。

核查限制：正文和首层平面图链接已打开，但图库页面未向抓取工具返回可检查的图像内容。本次没有逐图量取教室尺寸、走廊长度、卫生间位置，也没有验证四层楼梯坐标。此项目支持长廊和双端楼梯的拓扑关系，不支持将游戏的四层高度、全部房间功能或屋顶撤离设施归于该实楼。

## 2. 霍邱县城南九年一贯制学校建设项目

- 项目：安徽省六安市霍邱县城关镇；建设单位为霍邱县教育局。
- 来源性质：政府网站发布的建设项目环境影响报告表，编制日期2024年7月。内容是申报建设方案，不能据此断言已经按图竣工。
- [官方PDF：建设项目环境影响报告表](https://www.huoqiu.gov.cn/group3/M00/70/45/wKgSG2aaDiqALbr1ACDMxBWBY0g388.pdf)
- 定位：报告印刷页13，表2-1“主要建设内容一览表”（PDF第14页）。

已被表格支持的观察：

1. 小学有两栋四层教学楼，并以过道连接彼此及小学实验楼；这证明四层教学空间与连续交通连接是该真实项目方案的一部分。
2. 小学教学楼的连接过道区域安排合班教室、教师办公室、教师休息室；可借鉴“普通教室重复、公共节点插入辅助房间”的功能节奏。
3. 小学教学楼每层均有卫生间和楼梯间。资料没有在该表格中给出楼梯数量或精确位置。
4. 中学有三栋五层教学楼，通过过道连接，连接区域配置教师办公室，每层均有卫生间和楼梯间。
5. 中学实验楼一至三层配置理化生实验室、办公室及准备室；这些属于独立实验楼的真实功能，不应宣称与普通教室原本就在同一栋楼。

核查限制：已读取PDF文字；截图接口返回缓存错误，因此未完成图像核查。本来源支持楼层数和空间类型组合，并非已核验的逐层平面图。楼梯跨层对齐、走廊净宽、房间门数及屋面通行方式均未从本资料确认。

## 对本游戏原型的采用边界

- 将长条走廊、成排教室、两端楼梯作为基础空间骨架，比九宫格房间更接近参考项目1所描述的教学楼。
- 四个教学楼层、各层两个楼梯在相同平面位置连接，是本关卡的明确设计选择。参考资料支持多层教学楼和双端楼梯分别存在，不证明两者在同一参考实楼完整组合。
- 各层安排卫生间，局部设置办公室、实验室及准备室，用于建立房间差异。把独立实验楼功能集中到一栋关卡建筑中属于游戏改编。
- 屋顶直升机撤离、可通行平屋顶、障碍物、丧尸分布、资源点与门禁均为虚构玩法；本次没有任何来源证明上述学校存在直升机设施。
