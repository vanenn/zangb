# 灰城余生

一款以灰城灾后求生为题材的俯视角动作生存游戏。带领幸存者穿过感染者浪潮，在战斗中救援、招募同伴、搜刮装备，并组合队伍武器构筑。

## 八种基础武器

武器体系由三条轴组合而成：近战或远程、单体或群体、单次结算或持续跳伤。

| 攻击方式 | 目标 | 伤害节奏 | 职业与武器 |
| --- | --- | --- | --- |
| 近战 | 单体 | 单次 | 维修工 · 重型扳手 |
| 近战 | 单体 | 持续 | 消防员 · 救援电锯 |
| 近战 | 群体 | 单次 | 商场保安 · 警棍横扫 |
| 近战 | 群体 | 持续 | 环卫工 · 旋转清障刷 |
| 远程 | 单体 | 单次 | 猎人 · 蓄力重弩 |
| 远程 | 单体 | 持续 | 化工人员 · 酸液喷枪 |
| 远程 | 群体 | 单次 | 拆除工 · 投掷式破拆药包 |
| 远程 | 群体 | 持续 | 化学教师 · 自制燃烧瓶 |

化学教师、维修工和商场保安是三名开局角色。其他五组幸存者可以在整备阶段招募，加入后会自动使用自己的武器。

## 游戏内容

- 十波生存战，逐波增强的感染者潮和第十波首领。
- 枫箬中学、雨幕长街、长明百货三条路线；地图机关可以阻挡或引开尸群，也能制造爆炸。
- 八种基础武器各有专属改装，另有通用改装和十二件核心装备。
- 全队共用生命和四个装备槽；同类幸存者达到二、四、六人时提升对应武器协同。
- 攻击和拾取自动进行，玩家专注移动、救援、搜刮和机关操作。
- 本地离线运行，不依赖网络服务。

## 运行项目

1. 安装 Godot 4.7.2。
2. 在 Godot 项目管理器中导入本仓库根目录的 project.godot。
3. 打开项目后运行主场景（F6）或运行项目（F5）。

Windows 批处理脚本面向本地已有的发布程序；源码仓库不提交 dist/ 和 build/ 产物。Windows 导出请使用项目中的 export_presets.cfg 和对应版本的 Godot 导出模板。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 救援、搜刮、操作机关 | 靠近目标后按住 E |
| 查看同行者与协同 | Tab |
| 查看当前构筑 | B |
| 暂停 | Esc |
| 攻击、拾取 | 自动 |

## 项目结构

| 路径 | 内容 |
| --- | --- |
| main.tscn、scripts/ | 主场景、战斗、成长、队形、地图和界面逻辑 |
| data/ | 职业、幸存者、武器、改装、装备、敌人、地图和波次配置 |
| assets/ | 人物、地图、物件、视觉特效与许可证 |
| docs/ | 构筑指南、系统说明、地图样板与历史验收记录 |
| tests/ | 第三版历史规则与流程检查 |
| tools/ | 项目内容生成、更新、验证与打包脚本 |
