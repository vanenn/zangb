# 灰城余生 · 各寻生路

一款以灰城灾后求生为题材的俯视角动作生存游戏。带领幸存者穿过十波感染者，在战斗中救援、招募同伴、搜刮装备，并用武器改装建立队伍构筑。

> 当前仓库保存的是第三版项目源码。当前版本仍使用 15 种武器、12 名可招募幸存者、36 项武器与通用改装，以及 12 件核心装备。8 类武器体系是下一阶段的设计方向，尚未合入游戏。

## 游戏内容

- **十波生存战**：每波战斗约 60 秒，随后进入整备；逐波提升的感染者潮、第十波首领和两档难度组成主要挑战。
- **三张路线**：枫箬中学、雨幕长街、长明百货。地图机关可以改变尸群动向、封锁通路或制造爆炸。
- **三名开局角色**：教师、维修工、保安，各自拥有起始武器和路线加成。其他幸存者可以在游戏中救援和招募。
- **局内构筑**：每局最多选择 16 项一次性改装；搜刮获得核心装备，全队共用四个装备槽。
- **自动攻击与主动移动**：攻击会自动寻找目标；玩家需要移动、救人、搜刮并决定何时利用地图机关。
- **离线游玩**：游戏使用本地 Godot 项目、美术和合成音效，不依赖联网服务。

## 运行

### 从源码运行

1. 安装 Godot **4.7.2**。
2. 在 Godot 项目管理器中导入仓库根目录的 `project.godot`。
3. 打开项目并运行主场景（F6）或运行项目（F5）。

Windows 快捷脚本 `开始游戏.bat` 和 `学校地图样板.bat` 会启动 `dist/` 中的导出程序；源码仓库不包含这些发布文件。直接运行源码请从 Godot 编辑器启动。

### Windows 导出

项目包含 `export_presets.cfg`。请在本机安装匹配版本的 Godot 导出模板，并在编辑器中确认 Windows 导出预设的模板路径，再导出程序。项目内 `build/` 与 `dist/` 目录用于本地构建和发布产物，默认不提交到 Git。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 救援、搜刮、操作机关 | 靠近目标后按住 E |
| 同行者与职业协同 | Tab |
| 查看当前构筑 | B |
| 暂停 | Esc |
| 攻击、拾取 | 自动 |

长列表可用鼠标滚轮或滚动条浏览。交互优先处理救援，其次搜刮，再操作机关。

| 路径 | 内容 |

| `main.tscn`、`scripts/` | 主场景、战斗、成长、队形、地图和界面逻辑 |

## 运行规则检查

在安装 Godot 4.7.2 并导入项目后，可以从项目根目录执行规则检查：

```powershell
godot --headless --path . --script tests/v3.gd
godot --headless --path . --script tests/mechanisms_v3.gd
godot --headless --path . --script tests/builds_v3.gd
```

完整检查范围、战役模拟方法和已知限制见[验收记录](docs/VERIFICATION.md)。

## 当前状态

第三版已完成自动规则检查、固定构筑与战役模拟、实际窗口输入检查和 Windows 发布程序检查。自动模拟不能替代真人试玩；升级选择吸引力、长局节奏、地图机关的实际使用率与丧尸动作观感仍需要持续的玩家体验反馈。详见[验收记录](docs/VERIFICATION.md)。
